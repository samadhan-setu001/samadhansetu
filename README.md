# Samadhan Setu (समाधान सेतु)

**Civic Issue Reporting & Governance Platform with Proof of Work**

Samadhan Setu is a comprehensive civic-issue workflow platform connecting citizens, civic authorities, and field officers with transparent, tamper-evident verification.

## Architecture

- **Frontend**: Next.js (App Router, Tailwind CSS, TypeScript) located in `frontend/samadhan-setu`
- **Backend**: Supabase (Database, Auth, Row-Level Security, Edge Functions) located in `backend`

## Quick Start

### Frontend Development
Double-click `start-dev.bat` or run:
```bash
cd frontend/samadhan-setu
npm install
npm run dev
```

### Vercel Deployment
Double-click `deploy-vercel.bat` or run:
```bash
cd frontend/samadhan-setu
npx vercel --prod
```
